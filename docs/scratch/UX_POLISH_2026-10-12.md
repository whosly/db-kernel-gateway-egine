# Console UX polish plan (2026-10-12)

## Context
Post redesign (bc5376d) + theme switcher (6020e48). Goal: ship 3–6 high-impact interaction fixes this turn; no protocol/Prometheus work.

## Audit findings (code + prior smoke)
| Issue | Impact | Fix this turn? |
|---|---|---|
| Toast is plain text, no severity / dismiss | Errors look like success; hard to re-read | **Yes** — typed toast + dismiss |
| Destructive ops use native `window.confirm` | Breaks light/dark theme; jarring | **Yes** — in-app ConfirmDialog |
| Sidebar at ≤900px becomes full-width horizontal nav | Eats vertical space on tablet/phone | **Yes** — collapsible drawer + menu button |
| Instance filters lack count / clear | Discoverability after filter | **Yes** — N/M + 清除筛选 + empty CTA |
| Create dialog / drawer: no Esc | Keyboard trap friction | **Yes** — Esc closes overlay/drawer |
| SQL Ctrl+Enter ignores text selection | Common IDE expectation | **Yes** — run selection when selected |
| Table sticky headers inconsistent | Scroll context loss | Partial — ensure `.data-table thead` sticky in main.css |
| Form field-level validation beyond HTML5 | Nice-to-have | Defer |
| SQL line numbers / Monaco | Large scope | Defer |

## Self-check
- Does not change API/ACL contracts
- Toast API stays backward-compatible: `(msg, type?)` — existing `toast(msg)` still works
- Confirm provide returns `Promise<boolean>`; call sites swap `confirm(...)` → `await askConfirm(...)`
- Mobile nav defaults collapsed on narrow; desktop unchanged
- Theme tokens only; no hard-coded dark colors

## Out of scope
SQL Server TDS, Oracle, Keycloak E2E, Prometheus.
